# S for Solo

Add the `.amxd` device to a Live Set, then map the device's **Solo** control to
lowercase `s` in Key Map Mode. Turn off Live's **Computer MIDI Keyboard**
(also called Musical Typing) first; otherwise it intercepts the `s` key.

The v0.0.5 device has a minimal UI with the Solo control and setup reminder.
The user confirmed the shortcut works for both single and multiple selected
tracks after disabling Computer MIDI Keyboard.
